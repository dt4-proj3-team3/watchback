## 1. Web 팀 목표

> 조직의 Dependabot Alert와 Gold의 위험 변화 후보를 연결하고, 사용자가 재검토 근거를 확인하고 조치할 수 있는 Web 흐름을 제공한다.

재검토 Alert는 DS가 제공하는 고정 5건이 아니라, 위험 변화 후보와 조직의 실제 Dependabot Alert를 연결한 결과로 생성한다.
