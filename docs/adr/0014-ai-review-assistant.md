# ADR-0014: 근거 기반 읽기 전용 AI 검토 도우미

- 상태: Proposed
- 날짜: 2026-09-01
- 관련 이슈/PR:
- 대체하는 ADR:
- 대체된 ADR:

## Context

검토자는 Case, Candidate, Evidence, Dependabot Alert와 조치 범위를 직접 종합해야 한다. AI가 이 정보를 요약할 수 있지만 보안 판단이나 자동조치를 독자적으로 실행하면 제품 비목표와 사용자 통제를 침해할 수 있다.

## Decision

- AI는 현재 조직의 Watchback DB 데이터와 버전 관리된 설명 자료만 사용하는 읽기 전용 검토 도우미로 제공한다.
- 기본 Azure OpenAI 모델은 `gpt-5.6-luna`로 하고 `gpt-5.6-terra`는 평가용 상향 후보로 둔다.
- 초기 구현은 자동 모델 라우팅과 실시간 웹 검색을 포함하지 않는다.
- 수치와 현재 상태는 PostgreSQL 구조화 조회를 원본으로 사용하고 문서 검색이 필요할 때만 벡터 검색을 사용한다.
- 모든 답변은 확인한 Case, Evidence, Advisory 또는 Alert 출처를 포함한다.
- 근거가 부족하면 확인할 수 없음을 밝히고 실제 악용 여부, 패치 안전성, 위험 수용 또는 자동병합을 확정하지 않는다.
- 자유 질의 대화는 세션 단위로 유지하고 초기에는 영구 저장하지 않는다.
- 패키지 조치 상세의 `핵심 위험`과 `권장 조치`는 버전 관리된 프롬프트로 명시적 일괄 생성한 뒤 PostgreSQL에 영구 저장한다.
- 저장된 패키지 요약에는 프롬프트 버전, 모델, 근거 식별자와 생성 시각을 함께 기록한다. 상세 화면 진입은 LLM을 호출하지 않고 저장된 요약만 읽는다.
- 위험 수용과 PR 생성은 별도 사용자 동작으로 유지한다.
- 조직 ID 범위를 모든 조회 단계에 적용한다.

## Alternatives

- 범용 보안 챗봇은 답변 범위와 평가 기준이 불명확해 선택하지 않았다.
- AI가 위험 수용이나 PR 병합을 직접 실행하는 방식은 사용자 승인과 감사 경계를 침해해 선택하지 않았다.
- 모든 운영 데이터를 임베딩하는 방식은 최신 수치의 일관성을 보장하기 어려워 선택하지 않았다.

## Consequences

- 작은 모델과 제한된 도구로 비용과 환각 위험을 줄일 수 있다.
- 상세 화면 응답 시간과 모델 호출량은 사용자 조회 횟수에 영향을 받지 않는다. 데이터나 프롬프트 변경 시에는 명시적으로 백필을 다시 실행해야 한다.
- Azure OpenAI 리소스와 모델 배포, Backend 도구 호출 경계와 출처 계약이 필요하다.
- 모델 품질은 대표 질문 평가로 검증하고 필요한 경우에만 Terra 상향을 도입한다.

## Verification

- 조직 범위를 벗어난 데이터가 검색되거나 답변에 포함되지 않는지 확인한다.
- 대표 질문에 출처가 포함되고 근거 없는 확정 표현이 거부되는지 확인한다.
- 현재 패키지 그룹을 일괄 생성한 뒤 같은 그룹의 저장 행이 중복되지 않고 API가 저장된 요약만 반환하는지 확인한다.
- 위험 수용·PR 생성 API가 AI 응답만으로 호출되지 않는지 확인한다.
- Luna와 Terra의 정확성, 지연시간과 토큰 사용량을 같은 질문 세트로 비교한다.
